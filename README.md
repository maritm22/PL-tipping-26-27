# PL-Tippen Streamlit V2

Denne versjonen legger til deltakerkort med profilbilder og treffsikkerhetsstatistikk.

## Nye nøkkeltall
- Fulltreffere
- ±1 plass
- ±2 plasser
- ±3 plasser
- >3 plasser
- Treffsikkerhet innenfor ±1
- Gjennomsnittlig absolutt plasseringsavvik
- Bonuspoeng
- Rundepoeng (klart for kobling mot GW-historikk)

## Bilder
Legg bilder i `images/`. Eksempel:
`Ola Nordmann` -> `images/ola_nordmann.jpg`

Kjør lokalt:
`streamlit run streamlit_app.py`
